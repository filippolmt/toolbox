This tree has already been deepened once, deliberately — Mount Plan, Session Plan, Run Plan, Config Plan, Image Plan, Tool Catalog are real deep modules and CONTEXT.md records why each exists. What follows is the friction the last round left: three seams declared at the wrong width, one plan mutated mid-flight, and two places where a pure function was extracted for testability while the decision it serves stayed untested at the call site.

Suite is red as measured. TestLaunchProximo_MissingBinary (internal/bridge/proximo_test.go:66) fails inside a toolbox shell — see candidate 3.
