2. Creare `internal/container/attach.go`:
   - Package `container`
   - Import: `context`, `io`, `os`, `os/signal`, `syscall`, `golang.org/x/term`, `github.com/docker/docker/api/types/container`, `github.com/docker/docker/client`
   - Funzione `execShell(ctx context.Context, cli client.APIClient, containerID string) error`:
     a. `execConfig := container.ExecOptions{AttachStdin: true, AttachStdout: true, AttachStderr: true, Tty: true, Cmd: []string{"/bin/bash"}}`
     b. `execResp, err := cli.ContainerExecCreate(ctx, containerID, execConfig)`
     c. `resp, err := cli.ContainerExecAttach(ctx, execResp.ID, container.ExecStartOptions{Tty: true})`
     d. `defer resp.Close()`
     e. Salvare stato terminale: `fd := int(os.Stdin.Fd())`, `oldState, err := term.MakeRaw(fd)` -- se errore (non TTY), procedere senza raw mode
     f. Se raw mode attivo: `defer term.Restore(fd, oldState)` IMMEDIATAMENTE dopo MakeRaw (Pitfall 1)
     g. Setup signal handler per restore terminale su crash:
        ```go
        sigCh := make(chan os.Signal, 1)
        signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)
        go func() {
            <-sigCh
            if oldState != nil { term.Restore(fd, oldState) }
            os.Exit(0)
        }()
        ```
     h. Goroutine per terminal resize (SIGWINCH):
        ```go
        go func() {
            winchCh := make(chan os.Signal, 1)
            signal.Notify(winchCh, syscall.SIGWINCH)
            for range winchCh {
                w, h, _ := term.GetSize(fd)
                cli.ContainerExecResize(ctx, execResp.ID, container.ResizeOptions{Height: uint(h), Width: uint(w)})
            }
        }()
        ```
        Inviare resize iniziale subito dopo.
     i. I/O bidirezionale:
        ```go
        go func() { io.Copy(resp.Conn, os.Stdin) }()
        io.Copy(os.Stdout, resp.Reader)
        ```
     j. Dopo che io.Copy ritorna (utente fa exit/ctrl+d): ritornare nil

   ATTENZIONE (Pitfall 6): I segnali SIGINT devono essere intercettati e gestiti per restore del terminale, ma durante la sessione exec il raw mode fa si' che ctrl+c venga inviato come byte al container via stdin (io.Copy), non come segnale al processo Go. Questo e' il comportamento corretto.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> Docker daemon | Comandi Docker via socket Unix -- il daemon esegue con i propri privilegi |
| Config YAML -> mount paths | Path dalla config diventano bind mount nel container |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Elevation of Privilege | Docker socket mount | accept | Docker socket access e' root-equivalent by design. L'utente monta consapevolmente il socket per usare Docker dall'interno del container (non DinD). Documentato in PROJECT.md. |
| T-02-05 | Tampering | internal/container/lifecycle.go | mitigate | Verificare esistenza immagine con ImageInspect prima di ContainerCreate. Nome container fisso "toolbox" (D-03) previene container name injection. |
| T-02-06 | Denial of Service | internal/container/attach.go | mitigate | Terminal state restore via defer + signal handler. Timeout 10s su ContainerStop. Force remove come fallback. |
