   - Struct privata per parsing JSON streaming:
     ```go
     type buildMessage struct {
         Stream string `json:"stream"`
         Error  string `json:"error"`
     }
     ```
   - Funzione `BuildImage(ctx context.Context, cli client.APIClient, cfg *config.Config) error`:
     a. `ui.Info("Building image " + cfg.ImageRef() + "...")`
     b. Creare tar del build context: `buildCtx, err := createTarContext(cfg.Build.Context)`
     c. Se errore: ritornare con wrap
     d. Chiamare `cli.ImageBuild(ctx, buildCtx, types.ImageBuildOptions{Dockerfile: cfg.Build.Dockerfile, Tags: []string{cfg.ImageRef()}, Remove: true})`
     e. `defer resp.Body.Close()`
     f. Streaming output con `streamBuildOutput(resp.Body)` (D-12)
     g. `ui.Success("Image " + cfg.ImageRef() + " built successfully")`
   - Funzione privata `streamBuildOutput(reader io.Reader) error`:
     a. `scanner := bufio.NewScanner(reader)`
     b. Loop: `for scanner.Scan()` -> `json.Unmarshal(scanner.Bytes(), &msg)`
     c. Se `msg.Error != ""`: ritornare `fmt.Errorf("build error: %s", msg.Error)`
     d. Se `msg.Stream != ""`: `fmt.Print(msg.Stream)` (output diretto, senza buffering -- D-12)
     e. Ritornare `scanner.Err()`
   - Funzione privata `createTarContext(contextDir string) (io.Reader, error)`:
     a. Leggere `.dockerignore` se esiste: `ignorePatterns := readDockerignore(contextDir)`
     b. Creare pipe: `pr, pw := io.Pipe()`
     c. Goroutine: `go func() { tw := tar.NewWriter(pw); filepath.Walk(contextDir, func(...) { ... }); tw.Close(); pw.Close() }()`
     d. Nel Walk: per ogni file, controllare se matcha un pattern di ignore (usare `strings.HasPrefix` per directory patterns come `.planning/`, `.git/`). Se matcha, `return filepath.SkipDir` per directory o `return nil` per file
     e. Per file non ignorati: creare header tar con `tar.FileInfoHeader`, scrivere header e contenuto
     f. Ritornare `pr, nil`
   - Funzione privata `readDockerignore(contextDir string) []string`:
     a. Leggere `filepath.Join(contextDir, ".dockerignore")`
     b. Se non esiste: ritornare slice vuoto
     c. Parsare linee (ignorare righe vuote e commenti `#`)
     d. Ritornare lista di pattern

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> Docker daemon (build) | Build context (tar) inviato al daemon; il daemon esegue il build con i propri privilegi |
| .dockerignore -> tar creation | Pattern dal filesystem controllano quali file entrano nel build context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Information Disclosure | internal/build/build.go | mitigate | Rispettare .dockerignore nel tar context per evitare di inviare file sensibili (.planning/, .git/, segreti) al daemon. readDockerignore() parsa il file e filtra i path. |
| T-02-08 | Denial of Service | internal/build/build.go | accept | Build context potenzialmente grande se .dockerignore mancante. Rischio basso: l'utente controlla il proprio filesystem e .dockerignore esiste gia' nel repo. |
| T-02-09 | Tampering | cmd/completion.go | accept | Completion scripts generati da Cobra (codice fidato). L'utente sceglie se installarli. Nessun rischio aggiuntivo. |
</threat_model>
